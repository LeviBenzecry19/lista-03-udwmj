# lista-03-udwmj

Lista de Exercícios III (HTML, CSS e JavaScript) da disciplina **Usabilidade, Desenvolvimento Web, Mobile e Jogos (UDWMJ)** — Prof. Daniel Henrique Matos de Paiva.

| Exercício | Arquivos | O que faz |
|---|---|---|
| 1 – Área do círculo | `pratica03exercicio04.html` / `.css` / `.js` | Lê o raio e calcula `A = Math.PI * raio²`. |
| 2 – Volume da esfera | `pratica03exercicio05.html` / `.css` / `.js` | Lê o raio e calcula `V = 4/3 * Math.PI * raio³`. |
| 3 – Juros compostos | `pratica03exercicio06.html` / `.css` / `.js` | Lê capital inicial, taxa (%) e prazo e calcula `M = C * (1 + i)^t`. A taxa e o prazo devem estar na mesma unidade de tempo (ex.: % ao mês e meses). |

Cada página tem um formulário; ao clicar em **Calcular**, o JavaScript lê os valores dos campos, valida as entradas, aplica a fórmula e mostra o resultado na própria página.

## Como executar

Abra qualquer arquivo `.html` diretamente no navegador.

## Exemplos

- Raio 2 → área do círculo **12.57**
- Raio 3 → volume da esfera **113.10**
- Capital R$ 1.000,00, taxa 1% ao mês, 12 meses → montante **R$ 1.126,83**
